# Alpna Minj — Portfolio

A classy, elegant, responsive portfolio website with a dark blue + neon visual direction.

## Run
Open `index.html` in a browser.

## Customize
- Replace `alpna.minj@example.com` in `index.html` with your email.
- Add LinkedIn/GitHub links in the contact section if desired.
- Edit project descriptions and technologies in `script.js`.
- Edit colors, typography and layout in `style.css`.

No build tools or frameworks are required for this version.
